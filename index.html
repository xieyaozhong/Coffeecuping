01 · What is Cupping

不是考試
是比較

杯測是咖啡產業用來比較風味的方法。體驗版保留核心步驟，但把術語拆成更直覺的引導，讓第一次參加的人也能跟得上

先聞，再喝

從乾香、濕香到破渣後的香氣，感受溫度與水如何改變咖啡的氣味表現

啜吸，不是失禮

讓咖啡霧化進入口腔，讓香氣更容易到達鼻腔，也更容易比較酸甜、口感與餘韻

建立自己的座標

不用追求標準答案。你會練習把直覺感受整理成可以比較、記錄與重複使用的語言

02 · Sensory Map

從「好喝」
再往前一步

我們不會要求你硬背水果名稱，而是先從大分類找到方向，再逐步縮小到更清楚的描述

01

香氣 Aroma

花香、果香、堅果、可可、香料與烘焙氣息

02

酸質 Acidity

明亮、柔和、果汁感，或像柑橘、蘋果、莓果的感受

03

甜感 Sweetness

蔗糖、蜂蜜、焦糖或成熟水果般的甜感印象

04

口感 Body

茶感、絲滑、奶油、果汁感，與咖啡在口中的重量

05

餘韻 Finish

吞下後留下什麼，以及味道停留多久

01

認識杯測

工具、流程、風味輪與基本感官概念

02

聞乾香

先不喝，從研磨後的香氣開始建立印象

03

注水與破渣

觀察熱水加入後香氣如何改變與釋放

04

啜吸比較

比較酸甜、口感、乾淨度與不同咖啡的差異

05

交換答案

把每個人的描述放在一起，建立自己的感官資料庫

07 · FAQ

第一次參加
最常問的事

完全不懂咖啡也可以參加嗎？ ＋

可以。入門場就是以沒有杯測經驗的人為主要設計對象，會從香氣、酸甜與口感開始，不需要先背任何術語

杯測需要把每一杯都喝完嗎？ ＋

不需要。杯測主要是少量啜吸比較，也可以依自己的咖啡因耐受程度調整品飲量

活動前需要準備什麼？ ＋

建議活動前一小時避免香水、口香糖、重口味食物與大量咖啡，讓嗅覺與味覺保持相對乾淨

可以兩個人一起報名嗎？ ＋

可以，在報名表選擇參加人數即可。實際席位仍以主辦方回覆確認為準

確切地址在哪裡？ ＋

目前頁面以「台中市區」作為展示資訊。正式活動可在報名確認後提供完整地址，也可以直接把固定店址放進頁面設定

現在頁面送出後，主辦方會收到資料嗎？ ＋

目前不會。這是純前端 GitHub Pages 版本，資料只留在使用者裝置。你之後補上 Google Form、LINE OA、表單 API 或後端服務後，就能切換成正式線上收單
